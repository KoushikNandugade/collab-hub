COLLABHUB — END-TO-END APPLICATION DEMO

CollabHub-Demo.mp4: narrated 1080p walkthrough, with burned-in English captions.
CollabHub-Demo.srt: separate subtitle track.
Chapters.txt: navigation timestamps.
Narration.txt: spoken script.

The video records actual browser interactions with the same application code as
https://collab-hub-phi.vercel.app. It was recorded from the working local copy
because this workspace cannot directly access the production domain.

All accounts, profiles, invitations, projects, tasks, and messages shown are
isolated demonstration data. The working backend uses a separate local MongoDB
replica-set database; no production account or project was modified.

Covered: landing page, signup, onboarding, profiles, dashboard, explained
matching, project creation and recruiting roles, discovery, saved projects,
applications, acceptance and team access, tasks and persistence, resources,
activity, project discussion, invitations, direct chat, notifications, logout,
and protected-page redirection.

Narration is synthetic English speech generated with sherpa-onnx 1.12.40 and
the Piper en_US-lessac-medium voice. Model source:
https://github.com/k2-fsa/sherpa-onnx/releases/tag/tts-models
The voice model's model card and dataset license reference accompany this file.

Application source: https://github.com/KoushikNandugade/collab-hub
Recorded for Koushik Nandugade's application demonstration.
